# Download

## Official Source Download

- Figshare deposit (v1): https://doi.org/10.6084/m9.figshare.21431547.v1
- Source repository: https://github.com/sekilab/RoadDamageDetector
- Challenge dataset links are available from CRDDC 2022 pages referenced in the repository.

## Package Repository

- Task package: https://github.com/large-road-damage-datalake/rdd2022-object-detection

## Notes

- This package uses local RDD2022 train annotations in VOC format.
- Test images are not annotated. They count toward image totals and resolutions but not toward per-image annotation statistics.
